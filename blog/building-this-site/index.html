Building This Site

26 Sep 2026 · 2 min read

Update, October 2026: This post describes the original version. The current design takes inspiration from Mark Gottscho’s website, with pages for engineering and research, plus a shared home for projects and notes.

I wanted a homepage that felt less like a resume and more like a room I could live in.

The design is borrowed with admiration from Thariq Shihipar’s site: warm paper, gold ornaments, and a switch between a professional side and a personal side. The code is my own. It is an Astro static site, styled with Tailwind, and served by Caddy from a box in my house.

Two modes

The toggle at the top is the whole idea. Professional mode is navy and gold, and it holds the circuits, the patents and the jobs. Personal mode is cream, and it holds this blog, the homelab and the robot.

Click my photo and it flips. The whole switch is one attribute on the page:

document.documentElement.dataset.mode = 'personal'

CSS does the rest: colors, which sections show, and the photo flip.

Self-hosted

Everything runs on the same machine that serves our family photos and movies. There are no trackers, no web fonts from someone else’s CDN, and no JavaScript beyond the few lines that flip the mode.

I will write more here about the homelab, the LLM bots, and whatever else I break next.
